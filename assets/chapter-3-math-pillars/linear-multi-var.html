Linear Algebra

Multiple Variables

y = w₁x₁ + w₂x₂ + b
… or in general: y = w · x + b
Many inputs · one output · still linear, just bigger
01
Each input gets its own weight
Every xᵢ is multiplied by its weight wᵢ. The weight decides how much that input matters.
02
A line becomes a plane
With two inputs, the graph is a flat plane in 3D. With many inputs, a flat hyperplane in higher dimensions.
03
This is one neuron
A single neuron in any network is exactly this: a weighted sum of all incoming inputs, plus a bias.
y = w₁x₁ + w₂x₂ + b · two inputs draw a plane
