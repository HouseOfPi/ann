Single Variable

y = mx + b
One input · one output · a single straight line
x
The input
The variable you control — temperature, hours studied, pixel intensity. Whatever you feed in.
m
The slope (weight)
How steeply y rises as x increases. In a neural network this is the weight.
b
The intercept (bias)
Where the line crosses the y-axis when x = 0. In a neural network this is the bias.
y = mx + b · one input draws one line
