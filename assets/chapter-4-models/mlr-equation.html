General Form — Multiple Linear Regression
ŷ = w0 + w1x1 + w2x2 + w3x3 + … + wnxn
Applied to Housing Prices
Price = w0 + w1·SquareFeet + w2·Bedrooms + w3·Bathrooms + w4·Age + w5·CrimeRate + w6·LotSize
1 Training
Feed the model known houses — features and their true prices — and it learns the weights w₀…w₆ that fit the data best.
features + prices  →  solve for w
weights fixed
2 Prediction
With the weights now fixed, plug in any new house's features and the equation estimates its price.
w known  +  new features  →  ŷ
